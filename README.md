# 섹터 + 마켓브레스 대시보드

미국 섹터·테마의 상대강도와 Stockbee 방식 마켓브레스를 매일 아침 한 화면에서 본다.

- **시장** SPY · QQQ · DIA · IWM · VIX · US10Y · DXY
- **마켓브레스** Stockbee Market Monitor 전 항목 + 40일 추세 + 극단 자동 감지
- **섹터** GICS 11종 히트맵 (SPDR)
- **테마** 19종 랭킹 — 반도체·소프트웨어·클라우드·전력인프라·우라늄·E&P·방산·우주·로보틱스·사이버·양자·바이오텍·인프라·운송·금광·IBD50, 그리고 크립토 3종(WGMI·IBIT·ETHA)
- **로테이션** 3M 상대강도 × 1W 모멘텀 사분면

기간(1D~YTD)과 절대수익률 / 벤치마크 대비 상대강도를 버튼으로 바꿔 본다.
파일 하나짜리 웹페이지 + 하루 한 번 도는 데이터 생성 스크립트로 되어 있다.

```
sector-dashboard.html          화면. 이 파일 하나로 동작한다.
build_data.py                  data.json 을 만드는 스크립트
.github/workflows/daily.yml    매일 자동 실행
```

## 자동 수집 붙이기 (30분)

1. GitHub에 **public** 저장소를 만든다. (public이면 Actions가 무료로 무제한이다)
2. 위 세 파일을 올린다. `daily.yml` 은 `.github/workflows/` 안에 둔다.
3. Actions 탭 → `daily-data` → **Run workflow** 로 한 번 손으로 돌린다. 첫 실행은 10~30분 걸린다.
4. Settings → Pages → Source를 `main` 브랜치 루트로 지정한다.
5. 대시보드를 열고 `⋯` → **자동 수집 설정** 에 주소를 넣는다.
   ```
   https://<아이디>.github.io/<저장소>/data.json
   ```
6. 다음날부터는 07:30(한국시간)에 저절로 갱신된다. 갱신 버튼만 누르면 된다.

`data.json` 은 캐시가 남을 수 있다. 대시보드는 요청할 때마다 `?t=` 를 붙여 이를 피한다.

## 스크립트 사용법

```bash
pip install yfinance pandas numpy requests
```

## 마켓브레스 지표

**1순위: Stockbee 원본.** 스크립트가 Stockbee가 공개한 Market Monitor 구글시트를
직접 읽어와 병합한다 — 4%·비율·분기·월간·13/34·T2108·유니버스는 **원본 숫자 그대로**다.
시트 접근이 실패하면 아래 자체 계산으로 자동 폴백한다. `--no-stockbee` 로 끌 수 있다.

**자체 계산분.** 원본 시트에 없는 것들: 신고가−신저가, %>50MA·%>200MA,
맥클렐란 오실레이터·서메이션, 등락 종목수, 섹터별 4% 카운트. 폴백용 자체 브레스는
Stockbee가 공개한 TC2000 v12.4 스캔 공식 그대로 계산한다
(출처: stockbee.blogspot.com/2014/08/how-i-get-market-monitor-numbers.html).
필터는 전역이 아니라 **스캔별**로 다르다.

원본 시트 데이터는 Stockbee가 무료 공개한 것으로 개인 참고용으로만 쓴다.
재판매·재배포하지 말 것.

| 필드 | 원본 공식 | 필터 |
|---|---|---|
| `up4` / `dn4` | 당일 종가 ±4% 이상 | 당일 거래량 ≥ 10만주 **그리고** 전일보다 증가 |
| `r5` / `r10` | 5일·10일 누적 4%↑ ÷ 4%↓ | — |
| `q25u` / `q25d` | **65일 최저/최고 종가** 대비 ±25% | 20일 평균 달러볼륨 ≥ $250K |
| `m25u` `m25d` `m50u` `m50d` | 20일 **전 종가** 대비 ±25%·±50% | 위 + 20일 전 종가 ≥ $5 |
| `u13` / `d13` | **34일 최저/최고 종가** 대비 ±13% | 달러볼륨 ≥ $250K |
| `t2108`, `a50`, `a200` | 40·50·200일선 위 종목 비율(%) | 필터 없음 |
| `nh` / `nl` | 52주 신고가 / 신저가 | 필터 없음 |
| `adv` / `dec` | 상승 / 하락 종목 수 | 필터 없음 |
| `mco` / `mcs` | 맥클렐란 오실레이터(비율 보정식 EMA19−EMA39) / 서메이션 | — |

주의: **분기(Q25)와 13/34는 "기간 시작점 대비"가 아니라 "기간 내 최저/최고 종가 대비"다.**
이 정의 차이가 값을 크게 바꾼다.

T2108 계열은 Worden(TC2000) 지표라 유니버스까지 똑같이 재현할 수는 없다.
남는 차이는 유니버스(Telechart의 US common stocks 목록 vs 나스닥 상장목록)와
데이터 벤더 차이에서 오며, 수 % 수준이 정상이다. 방향과 극단 수준이 목적이다.

**읽는 법.** 브레스는 극단에서만 쓴다. 극단적으로 나쁜 브레스는 바닥·반등 신호로 잘 작동하지만,
극단적으로 좋은 브레스는 천장 신호로는 잘 듣지 않는다.

## 값이 다른 이유 점검표

대시보드 값이 다른 사이트와 다를 때, 오류 이전에 이것부터 확인:

1. **기준일** — 화면 상단 "기준 YYYY-MM-DD"가 비교 대상과 같은 날인가.
   data.json은 하루 한 번 생성된다. 장중 실시간 값과는 당연히 다르다.
2. **소스 라벨** — "Stooq 직접 · 지연 가능(참고용)"이면 데이터가 하루 늦거나
   분할 미반영일 수 있다. 자동 수집(data.json) 연결이 기준이다.
3. **기간 관례** — 1M = 21거래일이다. 달력 1개월로 계산하는 사이트와는 1~2일 어긋난다.
4. **가격 수익률** — 배당 재투자 미포함(대부분 사이트와 같은 관례).
5. **US10Y** — 소스(^TNX)가 %로 오기도, ×10 지수식으로 오기도 해서 스크립트가 자동 감지해 %로 맞춘다. 4~5%대가 정상.

## 상대강도(RS) 계산## 상대강도(RS) 계산

모든 기간(1D·1W·1M·3M·6M·YTD)을 각각 따로 계산한다. 비율식이다:

```
RS = ( (1 + 종목수익률) / (1 + SPY수익률) − 1 ) × 100
```

같은 기간의 SPY 대비 초과수익률(%)이며, SPY 자신은 모든 기간에서 0이 된다.
로테이션 사분면의 꼬리(최근 5일 경로)와 순위 변화(▲▼ = 전일 종가 기준
그룹 내 1M 절대수익률 순위 변동)도 data.json 의 시계열에서 계산된다.

## 섹터 분류 (섹터별 4% 돌파용)

무료로 전 종목 GICS 를 받을 방법이 마땅치 않아, 각 종목을 최근 120거래일
일간수익률 상관이 가장 높은 SPDR 섹터 ETF 에 붙인다. 근사값이며 상관이
낮은 종목(약 20~30%)은 미분류로 빠진다. 절대 숫자보다 섹터 간 비교용이다.

## data.json 형식

```json
{
  "asof": "2026-08-19",
  "universe": 4218,
  "bench": "SPY",
  "dates": ["2025-07-01", "..."],
  "series": { "SPY": [612.1, "..."], "XLK": ["..."] },
  "quotes": { "SPY": {"px":640.2,"d1":0.4,"w1":1.2,"m1":2.5,"m3":6.1,"m6":9.0,"ytd":9.2,
              "rs_d1":0,"rs_w1":0,"rs_m1":0,"rs_m3":0,"rs_m6":0,"rs_ytd":0,"a50":true,"a200":true} },
  "sectors": [ {"s":"XLK","up4":41,"dn4":9,"u5":120,"m25u":33,"n":610} ],
  "breadth": { "history": [ {"d":"2026-08-19","up4":312,"dn4":128,"r5":1.8,"...":0} ] }
}
```

`dates`+`series` 는 대시보드가 사분면 꼬리와 순위 변화(▲▼)를 계산하는 재료다.

직접 다른 데이터 소스를 쓰고 싶으면 이 형식만 맞추면 된다.

## 자동 수집이 안 될 때

- **직접 받아오기** — `⋯` 없이 갱신 버튼만 눌러도 Stooq에서 시세를 직접 받아본다.
  브라우저가 막으면(CORS) 실패한다. 브레스는 이 경로로는 채워지지 않는다.
- **붙여넣기** — `⋯` → 붙여넣기. 프롬프트를 복사해 Claude에 보내고 돌아온 JSON을 붙인다. 시세만 채워진다.

## 다른 자동화 방법

| 방법 | 장점 | 단점 |
|---|---|---|
| GitHub Actions (권장) | 무료, API 키 없음, 브레스까지 계산 | 첫 설정 필요 |
| Cloudflare Workers | 브라우저에서 바로 호출 | 전 종목 스캔은 여전히 무리 |
| Google Apps Script | 시트에 익숙하면 쉬움 | 지수·ETF까지만 |
| EODHD · Polygon · Tiingo | 전 종목 일봉을 한 번에, 가장 깔끔 | 월 비용 |
