# 섹터 + 마켓브레스 대시보드

미국 섹터·테마의 상대강도와 Stockbee 방식 마켓브레스를 매일 아침 한 화면에서 본다.

- **시장** SPY · QQQ · DIA · IWM · VIX · US10Y · DXY
- **마켓브레스** Stockbee Market Monitor 전 항목 + 40일 추세 + 극단 자동 감지
- **섹터** GICS 11종 히트맵 (SPDR)
- **테마** 19종 랭킹 — 반도체·소프트웨어·클라우드·전력인프라·우라늄·E&P·방산·우주·로보틱스·사이버·양자·바이오텍·인프라·운송·금광·IBD50, 그리고 크립토 3종(WGMI·IBIT·ETHA)
- **로테이션** 3M 상대강도 × 1W 모멘텀 사분면

기간(1D~YTD)과 절대수익률 / 벤치마크 대비 상대강도를 버튼으로 바꿔 본다.
파일 하나짜리 웹페이지 + 하루 한 번 도는 데이터 생성 스크립트로 되어 있다.

```
sector-dashboard.html          화면. 이 파일 하나로 동작한다.
build_data.py                  data.json 을 만드는 스크립트
.github/workflows/daily.yml    매일 자동 실행
```

## 자동 수집 붙이기 (30분)

1. GitHub에 **public** 저장소를 만든다. (public이면 Actions가 무료로 무제한이다)
2. 위 세 파일을 올린다. `daily.yml` 은 `.github/workflows/` 안에 둔다.
3. Actions 탭 → `daily-data` → **Run workflow** 로 한 번 손으로 돌린다. 첫 실행은 10~30분 걸린다.
4. Settings → Pages → Source를 `main` 브랜치 루트로 지정한다.
5. 대시보드를 열고 `⋯` → **자동 수집 설정** 에 주소를 넣는다.
   ```
   https://<아이디>.github.io/<저장소>/data.json
   ```
6. 다음날부터는 07:30(한국시간)에 저절로 갱신된다. 갱신 버튼만 누르면 된다.

`data.json` 은 캐시가 남을 수 있다. 대시보드는 요청할 때마다 `?t=` 를 붙여 이를 피한다.

## 스크립트 사용법

```bash
pip install yfinance pandas numpy requests

python build_data.py                 # 전체 (유니버스 5천개, 10~30분)
python build_data.py --limit 800     # 빠르게 시험

```

## 마켓브레스 지표

Stockbee Market Monitor 를 따른다. 유니버스는 미국 보통주(ETF·워런트·우선주 제외),
주가 $3 이상, 20일 평균 거래량 10만주 이상.

| 필드 | 뜻 |
|---|---|
| `up4` / `dn4` | 당일 4% 이상 오른 / 내린 종목 수. 거래량이 전일보다 늘어난 것만 센다 |
| `r5` / `r10` | 5일·10일 누적 4%↑ ÷ 4%↓ |
| `q25u` / `q25d` | 분기(65거래일) 25% 이상 상승 / 하락 종목 수 |
| `m25u` `m25d` `m50u` `m50d` | 월(20거래일) 25%·50% 이상 상승 / 하락 |
| `u13` / `d13` | 34거래일간 13% 이상 상승 / 하락 |
| `t2108` | 40일선 위 종목 비율(%) |
| `a50` / `a200` | 50일선 · 200일선 위 비율(%) |
| `nh` / `nl` | 52주 신고가 / 신저가 종목 수 |

T2108은 원래 Worden(TC2000) 지표라 그대로 가져올 수 없어 같은 정의로 직접 계산한다.
Stockbee 원본과 소수점까지 같지는 않다. 방향과 극단 수준이 맞으면 목적은 달성된다.

**읽는 법.** 브레스는 극단에서만 쓴다. 극단적으로 나쁜 브레스는 바닥·반등 신호로 잘 작동하지만,
극단적으로 좋은 브레스는 천장 신호로는 잘 듣지 않는다. 나머지 구간에서는 쓸모가 적다.

## 자동 수집이 안 될 때

- **직접 받아오기** — `⋯` 없이 갱신 버튼만 눌러도 Stooq에서 시세를 직접 받아본다.
  브라우저가 막으면(CORS) 실패한다. 브레스는 이 경로로는 채워지지 않는다.
- **붙여넣기** — `⋯` → 붙여넣기. 프롬프트를 복사해 Claude에 보내고 돌아온 JSON을 붙인다. 시세만 채워진다.

## 다른 자동화 방법

| 방법 | 장점 | 단점 |
|---|---|---|
| GitHub Actions (권장) | 무료, API 키 없음, 브레스까지 계산 | 첫 설정 필요 |
| Cloudflare Workers | 브라우저에서 바로 호출 | 전 종목 스캔은 여전히 무리 |
| Google Apps Script | 시트에 익숙하면 쉬움 | 지수·ETF까지만 |
| EODHD · Polygon · Tiingo | 전 종목 일봉을 한 번에, 가장 깔끔 | 월 비용 |
